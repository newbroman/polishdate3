# Polish Date Master (experiment)

> **Archived.** This is an earlier version, kept for reference. The current app is **Say the Date in Polish**: [repo](https://github.com/newbroman/too-obvious) · [live app](https://newbroman.github.io/too-obvious/). The numbers, dates and clock trainers are also combined in [Polska](https://github.com/newbroman/Polska).

An experimental branch of the Polish date trainer with a split calendar core and navigation modules. It was never published on GitHub Pages.

## Files

A static web app with no build step: `app.js`, `audio.js`, `calendar-core.js`, `cultural.js`, `events.js`, `holiday.js`, `index.html`, `manifest.json`, `navigation.js`, `numbers.js`, `phonetics.js`, `rules.js`, `sw.js`, `ui-renderer.js`, `year.js`.

To run it locally: `python3 -m http.server`, then open http://localhost:8000.

Built by Martin Hollingham.
